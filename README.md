Simple MNIST-based MLP perceptron written in modern C++ with SFML and ImGui GUI.

## About

**ForrAI** is a small educational project I created to better understand how neural networks work.
The application allows drawing digits on the canvas and classifying them using a fully connected neural network trained on the MNIST dataset.

Ispired by this translated article : https://habr.com/ru/companies/piter/articles/1021738/  
Original code : https://github.com/githubharald/cpp_mnist

---

## Technologies

- C++23
- SFML
- Dear ImGui
- OpenMP ( disabled in the release version )
